
# Quizkampen – Java Group Project

This repository contains a Java-based quiz game developed as a group project for the *Object-Oriented Programming and Java* course. The game is inspired by the popular mobile game **Quizkampen**, tailored for desktop use with a focus on simplicity and accessibility. This assignment also focused on working as a team in a manner that practise agile methodology with sprints, daily stand-ups, retrospectives, backlogs etc.

## Project Overview

The objective was to create a two-player quiz game with the following features:

- **Turn-based gameplay**: Players connect using TCP-IP, once two player have been connected they take turns selecting categories and answering questions.
- **Multiple categories**: Questions are organized into various categories.
- **Scoring system**: Points are awarded for correct answers, and scores are tracked per round and overall.
- **User-friendly GUI**: A graphical interface that displays questions, options, and scores. 
- **Customization**: Amount of questions and rounds can be set in the .properties file.

## Technologies Used

- **Programming Language**: Java
- **GUI Framework**: Java Swing
- **Version Control**: Git
- **Development Environment**: IntelliJ IDEA
- **Questions source**: [Open Trivia Database](https://opentdb.com/) JSON API
